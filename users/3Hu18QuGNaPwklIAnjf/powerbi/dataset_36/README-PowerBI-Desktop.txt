FinSight AI Power BI Desktop

This folder belongs to one authenticated FinSight user. In Power BI Desktop, set the existing Cleaned_Data query source to data/financial_data.csv and the Predictions query source to data/predictions.csv, then save and use Refresh. Additional visualization-ready CSV tables are in the same data folder. Do not connect this report to the shared MySQL database.

The Flask app generates data and copies the reusable PBIX template; it does not edit or create a PBIX file.
